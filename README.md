# Ocupação de Transportes Públicos (OTP)

Sistema de crowdsourcing para determinação da ocupação de transportes públicos (Metro e Comboios de Lisboa) baseado em sinais de comunicação sem fio e Aprendizagem de máquina.

## Estrutura do Repositório

- `/android`: Aplicação Android final (interface e recolha passiva de dados).
- `/jvm`: Servidor backend da aplicação.
- `/docs`: Descrição dos endpoints da API em formato YAML.
- `/other_contributions`: Aplicações de teste auxiliares e relatório.
